# Niladri Dey — Developer Portfolio

A static, responsive portfolio showcasing Niladri's projects, experience, and contact links.

## Run locally

Open `index.html` in a browser. The site uses no build step; images and the downloadable CV are in `assets/`.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`. GitHub Pages will serve `index.html` and the files in `assets/`.

## Project status

Project descriptions distinguish live work from prototypes and active development. Update the portfolio as implementation and deployment status changes.
